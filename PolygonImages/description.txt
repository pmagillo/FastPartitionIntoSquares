These are the images, containing polygons, that are used in the experiments of the paper.
They are given as png images.
They can be converted to binary files with Python program PNGtoBinary.py 
or by create4images.py, which does the same but creates also three rotated 
copies of the image (as done in the paper).

The file EXAMPLE.TXT, provided in the parent directory, explains how experiments were performed 
on each image.
